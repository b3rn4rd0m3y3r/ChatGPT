# WebAccess — Sessão 01

Primeira entrega do projeto: interface principal, navegação entre áreas, identificação do banco, cartões de resumo e telas iniciais de Tabelas, Consultas SQL e Relacionamentos.

## Como executar

1. Extraia a pasta `WebAccess_Sessao01`.
2. Abra `index.html` em um navegador moderno (Chrome, Edge ou Firefox).
3. Não é necessário instalar servidor ou dependências nesta etapa.

## Teste rápido

- Navegue pelas opções do menu lateral.
- Clique em **Nova tabela** e informe um nome. Nesta sessão, a inclusão é apenas demonstrativa e permanece na memória enquanto a página estiver aberta.
- Use o botão de lápis ao lado do nome do banco para renomeá-lo temporariamente.
- Abra **Sobre** para consultar a versão.

## SQL.js

Os arquivos SQL.js não são necessários na Sessão 01. Copie posteriormente `sql-wasm.js` e `sql-wasm.wasm` para a pasta `lib/`, quando formos integrar o motor SQLite. Mantenha os nomes dos arquivos exatamente como fornecidos pelo pacote.

## Limitações desta versão

- Ainda não cria tabelas reais nem campos.
- Ainda não armazena dados permanentemente.
- O editor SQL e o diagrama de relacionamentos são apenas prévias visuais.
- A criação de tabela nesta versão é uma demonstração de navegação, não uma operação de banco de dados.
